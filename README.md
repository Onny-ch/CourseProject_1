# Курсовая работа. Приложение для анализа банковских операций"

## Описание функционала:

### 1. Главная страница:
- Приветствие пользователя
- Информация по каждой карте (последние 4 цифры, сумма расходов, кэшбэк)
- Топ-5 транзакций по сумме платежа
- Курс валют
- Стоимость акций из S&P500
- - -

### 2. Страница событий:
- Расходы
- Поступления
- Курс валют
- Стоимость акций из S&P500
- - -

### 3. Сервисы:
- Выгодные категории повышенного кэшбэка
- - Возвращается JSON с анализом, сколько на каждой категории можно заработать кешбэка в указанном месяце года.
- Инвесткопилка
- - Накопление через округление трат в большую сторону по заданному порогу округления.
- Простой поиск
- - Возвращается JSON со всеми транзакциями, содержащими запрос в описании или категории.
- Поиск по телефонным номерам
- - Возвращается JSON со всеми транзакциями, содержащими в описании мобильные номера.
- Поиск переводов физическим лицам
- - Возвращается JSON со всеми транзакциями, которые относятся к переводам физлицам.
- - -

### 4. Отчеты:
- Траты по категории
- - Траты по заданной категории за последние три месяца.
- Траты по дням недели
- - Траты в каждый из дней недели за последние три месяца.
- Траты в рабочий/выходной день
- - Траты в рабочие и в выходные дни за последние три месяца.

## Установка:

#### 1. Клонируйте репозиторий:
```
git clone https://github.com/Onny-ch/CourseProject_1.git
```
#### 2. Установите зависимости:
```
poetry install 
```

## Использование:

Весь функционал тестируется из основного файла main.py

## Тестирование:

Добавлены модули тестирования имеющихся функций. Протестировать проект можно с помощью команды
`pytest`, проверить покрытие проекта тестами можно с помощью команды `pytest --cov`
